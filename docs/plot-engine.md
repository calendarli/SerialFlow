# 曲线引擎与验证

## 使用

曲线设置提供自动、WebGL2 和兼容绘图。自动优先尝试 WebGL2；失败后重新创建 Canvas，改用 Worker Canvas 2D；Worker 本身不可用时使用主线程 Canvas。故障原因显示在曲线设置中。切换引擎不清空原始样本或结束测量。

线宽以 CSS 像素计量，支持 0.5～8 px，默认 1.5 px。直线和阶梯都保留缺测与断线断点，不进行平滑插值。

“适配一次”使用当前范围并固定；“Y 自动”包含有效峰值，快速扩展并在小范围保持 1.5 秒后回缩。设置中可输入固定 Y 上下限。抑制异常模式仅影响显示量程，可能把极值裁在画面之外；原始统计仍包含极值。

绘图区滚轮缩放双轴，轴区域只缩放对应轴。缩放以鼠标位置为锚点，正反倍率互为倒数。边界钳制、点数取整仍会限制完全可逆性。绘图区拖动平移；开启游标时，点击与拖动优先用于测量。

时间模式以配置的秒数决定窗口，不随接收速率拉伸。各串口时间源：

- 接收时间：默认，电脑处理数据时记录的时间，不等于采样时间。
- 固定采样周期：首包按接收时间对齐，之后按配置周期累加；没有序号时不能识别丢包。
- 设备时间字段：使用解析出的数值字段（例如 `timestamp`），配置每单位的毫秒数和可选回绕模数。首包按接收时间对齐；未配置回绕而发生回退时按重启处理并断开连线。字段无效时该采样使用接收时间并显示提示。

时间源更改清空曲线和测量，避免混合不同时间基准。各数据源独立计时，但没有外部同步信息时不能保证跨设备精确对齐；若混合数据的时间回退，软件重新对齐并断开连线，提示时间源未同步。数据窗口沿用其输入的接收时间。

历史位置保存稳定采样 ID，缓存滚动不会静默换成另一组数据。所选历史被淘汰时显示最早可用样本及提示。游标默认为跟随视窗；选择固定采样后锁定 A/B 的采样 ID，数据被淘汰时显示提示，不以新数据替代测量。

## 实现边界

`PlotStore` 保留原始样本。每批样本编码为可转移的 Float64Array、来源索引和断点数组发送到 Worker，原始数值仍使用双精度。当前主线程与 Worker 各有一个有界缓存，没有启用 SharedArrayBuffer。

Worker 将样本按稳定 ID 分成最多 2048 点的块。绘图按横向密度保留首点、末点、峰和谷，分辨率分级，完整且未改变的块复用 CPU 几何和 GPU 缓冲。增长的尾块、被淘汰的头块、显示细节改变的块重建。缩放 Y 轴只更新坐标变换。当前不是无限历史或磁盘录制功能，容量仍为 100,000 个样本。

几何使用局部双精度原点，再上传相对单精度坐标。GPU 负责屏幕变换、线段宽度、圆端点及边缘抗锯齿。测量通过原始样本的分块统计缓存计算，绘图降采样不参与统计。平均值分块合并可能存在浮点舍入的末位差异。

接收通知采用 16 ms 合批，Worker 使用 requestAnimationFrame 并合并尚未绘制的请求。它不保证每个采样对应一帧，也不保证所有设备达到 60 fps。可见区间、通道、颜色和数据变化才触发绘制；界面数字仍随数据批次和异步统计更新。

当前坐标覆盖层保留归一化 SVG 坐标，渲染器按相同绘图区比例转换到实际像素再画线，避免线宽被非等比例拉伸。测量窗口保持现有独立窗口架构。

## 验证命令

从项目根目录使用 Bun：

```text
bun test tests/plot-engine.test.ts tests/plot-data.test.ts tests/plot-cursors.test.ts tests/plot-measurement.test.ts
bun run build
bun run test:ui:plot
bun run test:ui:plot-renderer
bun run test:ui:serial
```

Windows PowerShell 启用 WebGL2 UI 验证：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
$env:SERIALFLOW_PLOT_GPU = '1'
bun run test:ui:plot
Remove-Item Env:SERIALFLOW_PLOT_GPU
```

若执行环境设置了 `ELECTRON_RUN_AS_NODE`，应在测试进程环境中移除；不要修改应用代码规避该环境变量。

UI 测试使用模拟串口，覆盖引擎切换、初始化故障后回退、固定时间跨度、双游标、缓存滚动和 100,000 点 × 8 通道。图像检查使用真实 WebGL2 / Canvas 上下文，核对非空线条覆盖与清屏，并注入上下文丢失。隐藏窗口悬停样式使用 Chromium 伪类强制机制验证，避免依赖桌面鼠标位置。

输出位于 `.tmp/ui-smoke/`：`plot-performance.json`、`plot-performance-gpu.json`、`plot-renderer-result.json` 以及截图。CPU 提交耗时、主线程定时器延迟、游标往返延迟与实际呈现帧率是不同指标，不能互相替代。

这些检查不代表串口实机采样精度、安装包环境、Linux/macOS、其他显卡或远程桌面均已验证。上线前应在交付机器上确认 GPU 状态，并实际验证连续接收、断线恢复、多设备时钟和长时间内存稳定性。
